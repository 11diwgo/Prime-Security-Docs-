Política de Privacidad – Prime Security

1. Datos Recopilados
Prime Security recopila únicamente la información necesaria para su funcionamiento dentro de Discord: IDs de usuario, IDs de servidor y mensajes enviados a comandos del bot. No se recopilan datos personales adicionales.

2. Uso de los Datos
Los datos se utilizan exclusivamente para que el bot funcione correctamente y para mejorar la experiencia de los usuarios. No se venden, transfieren ni comparten con terceros.

3. Retención de Datos
La información recopilada se almacena de manera temporal y puede eliminarse a solicitud del usuario. Los usuarios pueden solicitar la eliminación de sus datos contactando al desarrollador.

4. Seguridad
Se aplican medidas básicas de seguridad para proteger los datos del usuario frente a accesos no autorizados.
